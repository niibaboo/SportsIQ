Team-totals lambda blends a recency-weighted last-5-games rate (65% recent) with season-to-date average, then prices with a Poisson distribution. Lines are set automatically below the model's projection for a safety margin. Game Total combines two teams' own separate scoring histories, not real head-to-head data — treat it with more caution than the single-team legs.
